# Code Tycoon

Code Tycoon est un jeu de gestion dans lequel le joueur développe
une carrière de programmeur.

Le joueur accepte des contrats de programmation, écrit lui-même
les solutions aux problèmes proposés, puis soumet son code.
Les solutions sont exécutées et testées automatiquement.

## Technologies

- Tauri
- TypeScript
- Rust
- Vite

## État du projet

🚧 En développement

Pour le moment, le projet contient principalement le prototype
du système de contrats et de gestion d'état.

## Installation

```bash
pnpm install
pnpm tauri dev
```
